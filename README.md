## 구현 기능(핵심 로직)
- 사용자 입력 기능
- 사용자가 커스텀구분자 생성을 요청했는지 검사하는 기능
- 커스텀구분자를 생성하는 기능
- 생성한 커스텀구분자가 디폴트구분자와 같은지 검사하는 기능
- 생성한 커스텀구분자의 길이가 1 이하인지 검사하는 기능
- 입력받은 문자열을 구분자로 분리하는 기능
- 분리한 문자열에 양의 정수 외의 문자가 있는지 검사하는 기능
- 분리한 문자열들을 각각 양의 정수로 변환하는 기능
- 변환한 숫자가 음수인지 검사하는 기능
- 숫자의 총합을 계산하는 기능
- 숫자의 총합을 출력하는 기능
- 모든 핵심 로직 기능을 실행시키는 기능
